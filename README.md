# Чаты службы поддержки

Небольшой учебный пример на Python без сторонних библиотек. Платформа хранит пользователей, операторов и историю чатов. Свободный оператор выбирается случайно; после закрытия чата пользователь может поставить оценку от 1 до 5.

## Запуск

В терминале из этой папки:

```powershell
py run_demo.py
```

Скрипт создаст 80 пользователей, 15 операторов и 120 чатов. Часть чатов останется открытой, часть будет закрыта без оценки. JSON-файлы появятся в папке `exports`.

Для проверки:

```powershell
py -m unittest -v
```

## Выгрузки

`run_demo.py` показывает все предусмотренные выгрузки:

- все чаты;
- чаты выбранного оператора;
- чаты выбранного пользователя;
- профили пользователей и операторов.

Выгрузки можно вызвать и из своего скрипта:

```python
platform.export_chats("exports/chats.json")
platform.export_chats_by_operator(1, "exports/operator_chats.json")
platform.export_chats_by_user(1, "exports/user_chats.json")
platform.export_users("exports/users.json")
platform.export_operators("exports/operators.json")
```

В профиле хранятся ФИО, город, дата рождения, должность и стаж. В сообщении сохраняются текст, отправитель и время отправки. Если все операторы заняты, новая беседа не создаётся.
